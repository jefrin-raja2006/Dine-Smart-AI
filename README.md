# 🍽️ DineSmart AI

> AI-Powered Restaurant Discovery & Review Platform

## 📌 Overview

DineSmart AI is a full-stack web application that helps users discover restaurants based on cuisine, location, ratings, and reviews. The platform allows customers to browse restaurants, post reviews, manage favorites, and receive AI-powered restaurant recommendations. Restaurant owners can manage their restaurants and menus, while administrators monitor the platform.

---

## 🚀 Features

### Customer
- User Registration & Login
- Search Restaurants
- Filter by Category & Location
- View Restaurant Details
- View Menu
- Rate Restaurants
- Write Reviews
- Save Favorite Restaurants
- AI-Based Restaurant Recommendations *(Future Enhancement)*

### Restaurant Owner
- Register Restaurant
- Manage Restaurant Details
- Manage Menu
- View Customer Reviews

### Admin
- Manage Users
- Manage Restaurants
- Verify Restaurants
- Remove Inappropriate Reviews
